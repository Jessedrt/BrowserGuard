Check before you click.

Inspect a URL or links pasted from an email. BrowserGuard checks local URL signals, your custom blocklist, and the downloaded domain feed.

Email text is scanned for up to 10 explicit HTTP or HTTPS links. Text and results are not saved or transmitted. A low score or no indicators is not a safety guarantee.

Protection status

On YouTube, ad blocking hides page ad slots and presses an available Skip button. The optional advance setting attempts to seek only when YouTube's ad state and countdown match the video timeline. If it affects playback, turn it off; network blocking and Skip assist remain active. These actions are not included in blocked-request counts.

Settings and threat intelligence

The extension downloads a public malware-domain list from URLhaus. Your browsing URLs are never sent to it. No API key or backend is used.

Checking feed…
Local custom blocklist and URL heuristics continue to work when the feed is offline. A feed entry is a threat-intelligence match; a URL heuristic is only suspicion.
BrowserGuard is a browser-level security tool. It is not a replacement for antivirus or endpoint security software.
