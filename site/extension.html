What it does

Four behaviours, each with a clear limit stated next to it.

URL warnings

Top-level navigation is analysed before the page settles. A risky address is replaced with a warning that names the specific reasons and offers a one-time way past.

Ad and tracker blocking

Packaged declarativeNetRequest rulesets block known ad and tracker requests. Each can be switched off independently, and an allowlist exempts sites you trust.

Malware feed matching

Domains are compared against the public URLhaus malware list, stored locally and updated daily. The list is downloaded — your browsing URLs never are.

Local link checker

The dashboard checks a pasted URL, or up to ten links from pasted email text, using the same engine as this site's checker. Nothing is uploaded or stored.

Install

Loading it in Chrome, Edge or Brave

  1. Download the latest ZIP from the GitHub releases page and extract it.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode, then choose Load unpacked.
  4. Select the folder that contains manifest.json.
  5. Pin BrowserGuard, open the popup, and use Update now in the dashboard to fetch the threat feed.
