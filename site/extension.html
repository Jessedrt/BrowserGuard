Protection that runs without being asked

The tools on this site are manual: you paste, you check. The extension applies the same analysis to every page you open, and blocks ad and tracker requests before they reach the network.

What it does

Four behaviours, each with a clear limit stated next to it.

URL warnings

Top-level navigation is analysed before the page settles. A risky address is replaced with a warning that names the specific reasons and offers a one-time way past.

Ad and tracker blocking

Packaged declarativeNetRequest rulesets block known ad and tracker requests. Each can be switched off independently, and an allowlist exempts sites you trust.

Malware feed matching

Domains are compared against the public URLhaus malware list, stored locally and updated daily. The list is downloaded — your browsing URLs never are.

Local link checker

The dashboard checks a pasted URL, or up to ten links from pasted email text, using the same engine as this site's checker. Nothing is uploaded or stored.

Install

Loading it in Chrome, Edge or Brave

  1. Download the latest ZIP from the GitHub releases page and extract it.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode, then choose Load unpacked.
  4. Select the folder that contains manifest.json.
  5. Pin BrowserGuard, open the popup, and use Update now in the dashboard to fetch the threat feed.

What it deliberately does not do

Stating limits is part of the design, not a disclaimer bolted on. These are the honest boundaries of a browser-level tool.

It is not antivirus software

It does not scan your computer, your files or installed programs, and it will not find malware already on a device. It protects what the browser can see: top-level addresses, subresource requests and the domains they point to.

A clean verdict is not a safety guarantee

The URL analysis looks for structural deception — lookalike brands, IP hosts, encoded tricks, suspicious paths. A phishing page on a professionally chosen domain can pass every check. “No indicators” means exactly that.

The feed has a size limit imposed by the browser

Chrome caps how many dynamic rules an extension may hold (5,000 below version 121, 30,000 from version 121 for block/allow rules). The extension applies as much of the downloaded feed as that budget allows and tells you the enforced count in Settings. The link checker and navigation analysis still read the full stored list.

Blocked-request counters need an unpacked install

Ad and tracker counts come from Chrome's onRuleMatchedDebug feedback event, which the browser only provides to unpacked extensions. In a packed install the blocking still works, but those counters cannot be populated. The extension counts what it observed instead of estimating.

YouTube ad handling is best effort

On YouTube, the extension hides known page ad slots and presses an available Skip button. An optional setting attempts a guarded seek only when YouTube's own ad state and countdown agree with the video timeline. YouTube serves some ads through normal video delivery, so an ad-free session is not promised.
