Link & phishing checker

Paste a suspicious link, or the links from an email, to see why it might be a phishing attempt. The analysis compares the address against known deception patterns; it does not open the page or contact the site.

Only explicit http and https links are extracted. The text itself is not analysed, stored or sent anywhere.

What gets checked

Lookalike brandsTypos such as paypa1.com
Address formIP hosts, deep subdomains
DeceptionEncoded and user-info tricks
ContextShorteners, HTTP logins
A clean result is not a safety guarantee. These are structural signals. A well-built phishing site on a normal-looking domain can pass every one of them.

How the score works

Each suspicious trait adds points. The total maps to a band:

  • 0 — no known indicators
  • 1–29 — low risk, minor oddity
  • 30–59 — suspicious, check carefully
  • 60+ — high risk, do not enter details

The number is a weighted tally, not a probability. “40/99” does not mean a 40% chance of fraud.

Try a safe example

These test addresses are reserved by the standards body and cannot belong to a real site:

  • https://example.com/ — clean
  • http://paypa1.example/verify — lookalike brand
  • http://192.0.2.4/login — IP address host
  • deep subdomain impersonation

Privacy

No request is made to the address you paste. No data leaves this page; there is no server component. Closing the tab discards everything.
