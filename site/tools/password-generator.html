Password generator

Random passwords and passphrases created with your device's cryptographic random source — the same mechanism browsers use for encryption keys. Nothing is uploaded and nothing is saved.

—

— —

Each word is drawn from a 256-word list, so every word adds exactly 8 bits. Four words give 32 bits; six give 48.

Where to use it

  • One password per account. Generate, paste into your password manager, and let it remember.
  • Generate again before you copy. Each click creates a new value; the page keeps only the one on screen.
  • Check the rules first. Some sites still reject very long passwords or symbols — adjust the options rather than shortening the result.

How it is generated

The generator calls crypto.getRandomValues() and rejects values outside an even range, so every character has an equal chance. It does not use Math.random(), which is not suitable for secrets.

Passwords are shuffled after generation so the required character types are not always in the same position.

Privacy

Generation happens on your device. This page makes no network requests and stores nothing — not in cookies, not in local storage, not in the URL.

Random vs passphrase

A 20-character random password is far stronger than any passphrase you can memorise. Use random values in a manager; use a passphrase only for the manager's master password or a device login.
